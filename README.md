# Forma Studio — концептуальное портфолио

Статическая витрина цифровой студии и три самостоятельных демо-проекта. Все бренды и кейсы вымышлены и созданы как учебные концепции; сайт не заявляет о реальных клиентах или выполненных заказах.

## Проекты

- [Steppe Coffee](https://alichamp.github.io/ali-portfolio/projects/steppe-coffee/) — концепция магазина specialty-кофе с интерактивной корзиной-счётчиком.
- [Move Studio](https://alichamp.github.io/ali-portfolio/projects/move-studio/) — wellness-лендинг с фильтром тренировок.
- [SOMA Interiors](https://alichamp.github.io/ali-portfolio/projects/soma-interiors/) — портфолио интерьерной студии с фильтром кейсов.

Сайт работает как статические HTML/CSS/JavaScript страницы без сборщика.
